# AulaFrontEnd

## Comandos Git

- `git status` → Visualizar as mudanças.
- `git add .` → Adicionar arquivos para stage.
- `git commit -m "mensagem"` → Salvar alterações no repositório local.
- `git push` → Enviar alterações para o repositório remoto.
